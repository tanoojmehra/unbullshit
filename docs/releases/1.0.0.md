# Unbullshit v1.0.0

First stable public release of four independent, portable Agent Skills:

- `unbullshit`: everyday scope and complexity discipline.
- `unbullshit-plan`: founder interviews and major project decisions.
- `unbullshit-audit`: evidence-led review of projects, architecture and direction.
- `unbullshit-improve`: practical, focused improvements.

## Distribution

- Skills CLI installation across supported agents.
- Claude Code native plugin files and Codex portable/compatibility packaging.
- Opt-in Cursor project rule and `AGENTS.md` template.
- Compatibility documentation, troubleshooting and example conversations.
- SVG brand identity.

## Quality

- Structural validation, regression tests and CI Skills CLI installation smoke tests.
- Verification status explicitly distinguishes file installation from native host invocation and model behavior.
- No hooks, background agents, MCP servers, tracking, or permissions are required.

## Install

```sh
npx skills add tanoojmehra/unbullshit --list
npx skills add tanoojmehra/unbullshit --skill '*' -y
```

Full instructions: [installation guide](../../docs/install.md). Behavioral benefits are not yet claimed as benchmark-proven.
