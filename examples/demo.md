# Unbullshit — 90-second guided demonstration

This is a **scripted walkthrough** you can repeat in an installed agent, not a recorded test or actual model transcript.

**0:00 — Discover and install**

```sh
npx skills add tanoojmehra/unbullshit --list
npx skills add tanoojmehra/unbullshit --skill '*' -y
```

**0:20 — Plan:** Ask, "Use unbullshit-plan. I want to build an appointment-booking product. Interview me about the choices that actually matter, explain options, and recommend a realistic first release."

Look for one high-impact question and an informed recommendation—not a giant architecture at the first reply.

**0:45 — Audit:** Ask, "Use unbullshit-audit to challenge this proposal. What is unsupported or unnecessary? What complexity is justified? State what you couldn't verify."

Look for actual evidence and the possibility of a zero-findings conclusion.

**1:05 — Improve:** Ask, "Use unbullshit-improve to make the reminder settings clearer, without redesigning the product."

Look for targeted changes and checks, not a new platform.

**1:25 — Everyday:** Ask, "Use unbullshit while adding CSV export. Keep the change small, correct and verified."

Look for focused execution and no unnecessary founder interview.
